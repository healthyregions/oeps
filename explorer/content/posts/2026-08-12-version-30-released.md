---
title: Version 3.0 Released
summary: The latest release of OEPS (v3.0) includes major updates to improve
  usage accessibility, infrastructure updates, and refined data resources.
date: 2026-08-12
---
Explore the latest version of OEPS to take full advantage of all the updates. In this major release, we include multiple changes, including:

- More resources for best practices in how to access data, with usage tips
- Updated code resources & insights section
- New Data Inclusion Criteria page for transparency
- New Blog to share Latest Updates
- Improved Navigation Architecture
- Improved Data Inventory 
- Multiple bug fixes and data improvements, especially for spatial access calculations over time

On the infrastructure end, we also improved backend/registry automation, cleaned up the repository for release packaging, and made multiple improvements for the user experience with increased reliability and metadata updates.

Please check out the full list of updates, authors and contributors, and further details at: [https://zenodo.org/records/21909862](https://zenodo.org/records/21909862).
